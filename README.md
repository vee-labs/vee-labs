# Vee Labs

> Innovative development and research — open source projects and experimental platforms.

Vee Labs is a small, forward-thinking initiative focused on building useful tools and exploring ideas at the edge of modern web, data, and developer tooling. Everything here is open source and welcoming of collaboration.

## What we're working on

- **[vee-labs](https://github.com/vee-labs/vee-labs)** — this repository: organization profile and the public documentation site for the lab.

More projects will land here as they take shape. Watch the org or check back to see what's new.

## Documentation

The full documentation site is built with [VitePress](https://vitepress.dev/) and lives under [`docs/`](./docs/). It is published via GitHub Pages on every push to `main`.

- Getting started: [`docs/guide/`](./docs/guide/index.md)
- API reference: [`docs/guide/api.md`](./docs/guide/api.md)
- Contributing: [`docs/guide/contributing.md`](./docs/guide/contributing.md)

To run the docs locally:

```bash
cd docs
npm install
npm run dev
```
