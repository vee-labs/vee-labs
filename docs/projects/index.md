# Projects

A collection of apps and tools built at Vee Labs.

## Mobile Apps

### [BreachGuard](/projects/breachguard)

> Privacy-first password and email breach monitor for Android and iOS.

BreachGuard tells you if your passwords or email addresses have been exposed in a data breach — without ever sending your credentials anywhere. Built with Flutter for both Android and iOS.

**Stack:** Flutter, Firebase, HaveIBeenPwned API, RevenueCat, AdMob

---

### [ACServiceApp](/projects/acservice)

> Field service ticketing system for AC technicians.

A native Android app for managing air-conditioning service jobs. Technicians can log tickets, track status, add comments, and close jobs — all synced in real time via Firestore.

**Stack:** Kotlin, Android, Firebase Firestore, Firebase Auth, MVVM
